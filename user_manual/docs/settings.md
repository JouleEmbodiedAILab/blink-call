# 设置

完成首次测试后，可以根据患者的实际情况调整软件。日常使用一般不需要频繁修改设置。

打开主界面左上角的“设置”，修改完成后点击“保存”。

## 我想调整什么

| 需要调整的内容 | 前往页面 | 建议 |
| --- | --- | --- |
| 呼叫需要完成哪些睁眼、闭眼动作 | [眨眼动作设置](blink-pattern.md) | 先使用默认设置测试，再逐项微调 |
| 使用哪个摄像头，或者启用备用摄像头 | [摄像头设置](camera.md) | 普通使用保持“本地摄像头” |
| 铃声、音量、播放时长和步骤提示音 | [提醒声音设置](audio-alert.md) | 保存前先试听，并检查系统音量 |
| 摄像头或人脸长时间未检测到时报警 | [提醒声音设置](audio-alert.md) | 可分别设置两种异常的报警等待时长 |
| 语言、亮暗模式、录制、日志和恢复默认值 | [其他设置与技术支持](advanced.md) | 录制和日志通常只在排查问题时开启 |

## 修改设置时的建议

- 每次只修改一类设置，保存后立即完成一次测试呼叫。
- 调整眨眼动作时，以患者能稳定完成且不过度疲劳为准。
- 调整摄像头后，回到主界面确认画面连续、双眼清楚可见。
- 调整声音后，同时检查软件音量和电脑或蓝牙音箱的音量。
- 如果设置被改乱，可以在“设置 → 其他 → 恢复默认设置”中恢复，然后重新测试。

## 设置没有生效

请确认已经点击设置窗口底部的“保存”。如果问题仍然存在，请查看[遇到问题](troubleshooting.md)。
