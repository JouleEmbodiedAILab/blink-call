# Settings

After the first successful test call, you can adjust the software to suit the patient. Settings usually do not need frequent changes during daily use.

Open **Settings** at the top left of the main screen. After making changes, click **Save**.

!!! warning "Disclaimer"
    This tool is intended only to support caregiving and cannot replace human supervision. Do not reduce or omit necessary human supervision because you use this tool.

## What Would You Like to Adjust?

| What to adjust | Page | Suggestion |
| --- | --- | --- |
| The eye-open and eye-closed actions needed for a call | [Blink Pattern](blink-pattern.md) | Test the defaults first, then make small changes |
| The camera to use or a fallback camera | [Camera](camera.md) | Keep **Local camera** selected for ordinary use |
| Ringtone, volume, playback duration, and step prompts | [Audio Alert](audio-alert.md) | Preview the sounds and check the system volume |
| Alerts when the camera image or face remains missing | [Audio Alert](audio-alert.md) | Set separate delays for the two conditions |
| Language, theme, recording, logs, and restoring defaults | [Advanced](advanced.md) | Recording and logs are usually needed only for troubleshooting |

## When Changing Settings

- Change one group of settings at a time, then save and complete a test call.
- Choose blink actions the patient can complete reliably without excessive fatigue.
- After changing the camera, return to the main screen and check for a continuous view with both eyes clearly visible.
- After changing audio settings, check the software volume and the computer or Bluetooth speaker volume.
- If settings have become confusing, use **Settings → Others → Restore defaults**, then test again.

## Changes Have Not Taken Effect

Make sure you clicked **Save** at the bottom of the settings window. If the problem continues, see [Troubleshooting](troubleshooting.md).
