# Settings

This section contains settings instructions for blink calls, camera, alert sounds, and other supporting features.

## Contents

- [Blink Pattern](blink-pattern.md): Adjust the eye-open and eye-closed sequence required to trigger a call.
- [Camera](camera.md): Select the camera and make sure the software can clearly see the patient's eyes.
- [Audio Alert](audio-alert.en.md): Adjust the alert sound, volume, playback duration, step prompt sound, and automatic camera or face alerts.
- [Advanced](advanced.md): Switch language and light/dark mode, and use recording, debug, and restore-default settings.
