# 眨眼呼叫 用户手册

**眨眼呼叫**是一款为渐冻症患者设计的辅助呼叫软件。患者按照预先设置的睁眼、闭眼动作完成眨眼序列后，电脑或蓝牙音箱会播放提醒声音，帮助患者呼叫家属或照护者。

## 从这里开始

### 我是第一次使用

请按照[首次使用](first-use.md)依次完成下载、解压、模型文件下载、摄像头设置和测试呼叫。

### 我已经配置完成

请查看[日常使用](daily-use.md)，确认每天使用前需要检查的项目，以及如何触发和停止呼叫。

### 软件没有正常工作

请进入[遇到问题](troubleshooting.md)，按照页面提示检查软件、模型文件、摄像头、眨眼识别和提醒声音。

## 适合谁使用

- 说话困难，无法方便地发出呼叫声音。
- 手部操作困难，无法稳定点击按钮或使用实体呼叫器。
- 可以通过睁眼、闭眼完成简单动作。
- 有家属或照护者协助完成首次配置和测试。

## 使用前需要准备

- 一台 Windows 电脑。
- 一个能够清楚拍到患者双眼的摄像头。
- 电脑扬声器或蓝牙音箱。
- 首次下载模型文件时可用的网络连接。

## 正式使用前

请让患者和照护者共同完成至少一次测试呼叫，并确认：

- 摄像头画面连续、清楚，患者的双眼完整可见。
- 患者能够完成当前设置的眨眼序列。
- 电脑或蓝牙音箱的提醒声音足够清楚。
- 照护者知道如何停止提醒声音。

软件或使用环境发生变化后，例如更换摄像头、移动电脑或调整眨眼动作，应重新完成一次测试呼叫。
