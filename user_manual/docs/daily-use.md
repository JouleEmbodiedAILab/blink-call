# 日常使用

完成首次配置后，日常使用只需要打开软件、检查摄像头和声音，然后按当前设置的眨眼序列触发呼叫。

## 使用前快速检查

每次开始使用时，请由家属或照护者确认：

- `BlinkCall.exe` 已经打开。
- 主界面正在连续显示摄像头画面。
- 患者的面部和双眼完整、清楚，没有被遮挡。
- 顶部眨眼进度条可见。
- 电脑扬声器或蓝牙音箱已经连接，音量合适。

![正常显示患者画面和顶部进度条的软件主界面](images/home-main-window.jpg)

!!! tip
    更换摄像头、移动电脑、改变患者位置或修改眨眼动作后，应重新完成一次测试呼叫。

## 触发呼叫

按照当前设置的顺序完成睁眼、闭眼动作。

软件当前的默认序列为：

**睁眼 1.5 秒 → 闭眼 1 秒 → 睁眼 1 秒 → 闭眼 1.5 秒**

如果已经自定义过动作，请以软件设置中显示的“眨眼序列”为准。

## 看懂顶部进度条

顶部进度条显示当前需要完成的动作以及完成进度：

- 浅绿色表示睁眼阶段。
- 浅黄色表示闭眼阶段。
- 深绿色表示当前已经完成的进度。

每个阶段都要保持当前状态，直到该阶段完成。完成一个阶段后，请在 3 秒内开始下一个阶段，否则整个序列会重新开始。

![顶部进度条跟随睁眼和闭眼动作前进](images/quick-start-call-alert.gif)

## 呼叫触发后

完成整个序列后，软件会播放提醒声音并显示呼叫提醒界面。

如果设置了固定播放时长，铃声会在达到时长后停止。如果设置为“无限时长”，铃声会持续播放，直到有人停止。

如需提前停止，患者或照护者可以点击呼叫提醒界面。

![点击呼叫提醒界面提前停止铃声](images/quick-start-call-alert.jpg)

## 使用过程中需要注意

- 不要让头发、被子、手或眼镜边框遮挡双眼。
- 环境光线或患者位置发生明显变化时，重新检查识别效果。
- 摄像头短暂断开时，软件会自动尝试恢复；重新插入后请等待画面恢复。
- 铃声必须足以让照护者听到，尤其是在房间距离较远或环境嘈杂时。
- 如果患者完成动作感到疲劳，请在照护者协助下调整序列，不要勉强完成过长的动作。

## 登录后自动启动和系统托盘

Windows 打包版默认启用“任意用户登录后自动启动”，无需在设置中勾选。首次运行时，BlinkCall 会请求一次 Windows 管理员授权来注册守护服务。服务会在任意活动用户会话中启动 BlinkCall；程序意外退出或被强制结束时会自动重启。请先将程序放在所有用户都能读取、普通用户不能修改的固定位置，再批准授权。各用户的设置保存在各自的 Windows 用户数据目录中。

软件启动后会显示在系统托盘中。点击窗口右上角的关闭按钮会隐藏到托盘，右键托盘图标可以重新显示窗口或退出软件。

如需关闭自动启动，请在 **设置 → 常规** 中取消“任意用户登录后自动启动”并保存设置；Windows 会再次请求管理员授权。此开关对整台电脑的所有用户生效。升级旧版时，原有的关闭状态会在首次运行新版时迁移为默认开启，之后手动关闭的选择会保留。

## 没有正常触发

请先观察主界面显示的内容：

- 没有画面：查看[摄像头没有画面](troubleshooting.md#camera-no-image)。
- 显示未检测到人脸或关键点无效：查看[检测不到患者面部或双眼](troubleshooting.md#face-eyes-not-detected)。
- 进度条不动或反复清零：查看[眨眼进度不动或反复重新开始](troubleshooting.md#blink-progress)。
- 呼叫出现但没有声音：查看[听不到提醒声音](troubleshooting.md#no-sound)。
