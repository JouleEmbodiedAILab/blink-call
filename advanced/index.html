    其他设置与技术支持¶

    本页包括语言、界面显示以及排查问题时使用的录制、日志和恢复默认设置。日常呼叫一般不需要开启录制或调试模式。

    切换语言¶

    进入：

    设置 → 常规 → 语言

    可以选择中文或 English。点击“保存”后，软件界面会切换到所选语言。

    切换亮色或暗色模式¶

    进入：

    设置 → 常规 → 亮暗模式

    可以选择亮色模式或暗色模式。这个设置只改变界面外观，不影响摄像头识别和呼叫功能。

    录制当前相机数据¶

    这个功能用于保存一段当前摄像头画面，帮助开发者或工作人员排查识别问题。普通日常使用不需要开启。

    进入：

    设置 → 其他 → 录制当前相机数据

    操作步骤：

    1. 设置最长录制时长。
    2. 选择本地电脑文件夹。
    3. 点击“开始录制”。
    4. 软件返回主界面并开始录制。
    5. 需要提前结束时，点击主界面上的停止录制按钮。

    保护患者隐私

    摄像头录制可能包含患者面部和周围环境。录制和分享前应征得患者或监护人同意。不要把包含敏感画面的文件直接上传到公开的 GitHub 问题中。

    开启调试模式和日志¶

    调试模式用于显示软件运行信息。工作人员需要查看识别状态或排查异常时再开启。

    进入：

    设置 → 其他 → 调试模式

    如果需要将日志保存为文件：

    1. 开启“调试模式”。
    2. 将“是否保存至本地”设为“是”。
    3. 选择本地日志目录。
    4. 点击“保存”并重新操作，直到问题再次出现。

    调试模式开启后，所选目录还会生成单独的 audio_status.log。它记录音频输出设备变更、铃声文件和音量、加载/播放状态、播放请求和停止事件，可用于排查“已触发呼叫但没有声音”的问题。该文件会滚动保存，保留最近的几份记录。

    问题排查结束后，可以关闭调试模式，避免主界面持续显示技术信息。

    恢复默认设置¶

    如果动作、摄像头、声音或界面设置被改乱，可以进入：

    设置 → 其他 → 恢复默认设置

    确认后，软件会恢复默认配置并关闭设置窗口。

    恢复默认设置不会删除已经下载的模型文件，但会重置眨眼动作、摄像头编号、声音和界面等设置。恢复后应重新检查摄像头，并完成一次测试呼叫。

    向工作人员或开发者反馈¶

    提交问题前，请先查看遇到问题。

    如果仍然无法解决，可以通过GitHub Issues反馈，并尽量提供：

    • 软件版本和 Windows 版本。
    • 问题发生前执行的操作。
    • 主界面显示的完整提示文字。
    • 预期结果和实际结果。
    • 不包含敏感信息的截图。
    • 工作人员明确要求时提供的日志。

    除非工作人员确认确有必要并说明安全的传输方式，否则不要公开上传摄像头录制。
